# Эмпирический анализ временной сложности алгоритмов (C# / WPF)

Полный перенос Python/PyQt-приложения на C# (.NET 8, WPF) с сохранением всей
логики: те же алгоритмы, реестр, БД с кэшем замеров, аппроксимация методом
наименьших квадратов, 2D-графики, вращаемая 3D-поверхность, режим «Сравнить
алгоритмы». Добавлено: 3 новых алгоритма и визуализация.

## Запуск

Нужны Windows и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```
dotnet run -c Release --project src/LabProject.App       # приложение
dotnet run -c Release --project src/LabProject.Check     # диагностика (аналог check_setup.py)
```

или откройте `LabProject.sln` в Visual Studio 2022 и запустите проект `LabProject.App`
(конфигурация **Release** - для честных замеров).

## Что нового

**Алгоритмы (Часть III):** Флойд–Уоршелл `O(n³)`, БПФ `O(n log n)`, Кнут–Моррис–Пратт `O(n)`.
БПФ работает для любого n: степени двойки - радикс-2 Кули–Тьюки, остальные -
алгоритм Блюстейна. На графике времени БПФ для произвольных n видны «ступеньки»
(размер внутренних БПФ округляется до степени двойки) - это не ошибка.

**Визуал:**
* вкладка **«Визуализация алгоритма»** - пошаговая анимация для каждого из 15
  алгоритмов (столбики для сортировок, таблицы для матриц/LCS, граф + матрица для
  Флойда–Уоршелла, диаграмма «бабочек» для БПФ, текст/шаблон/π-таблица для КМП,
  стек вызовов для степени). Кнопки: старт/пауза, шаг вперёд/назад, ползунок кадра,
  скорость, «Новые данные»;
* современное оформление: градиентная шапка, скруглённые карточки с тенями, собственные
  стили полей, списков, флажков, ползунков и вкладок; бейджи частей задания (I–IV) в списке алгоритмов;
* плашки статистики под графиком: модель, константа C, MSE, число точек, время расчёта, доля из кэша;
* график плавно «рисуется» (точки появляются по очереди, затем кривая аппроксимации с заливкой),
  3D-поверхность «вырастает»; вкладки переключаются с плавным проявлением;
* в анимациях алгоритмов - легенда цветов (что значит жёлтый, красный, зелёный…);
* 3D-поверхность вращается мышью;
* кнопка **«Сохранить изображение…»** (PNG или SVG) для текущего графика/кадра.

Превью - в папке `docs/`.

## Структура

```
src/LabProject.Core    алгоритмы, реестр, кэш, БД, аппроксимация, построение графиков и анимаций
  Algorithms/          Vectors, Matrices, Custom (LCS), Power, Graphs, Fft, StringSearch
  Core/                Benchmark (реестр + раннеры), BenchmarkCache, Approximation, ExperimentService
  Db/                  SqliteResultStore (схема как в Python-версии)
  Visual/              Scene (векторные примитивы), Charts, Surface3D, Animations/
src/LabProject.App     WPF-оболочка: окно, SceneView (рисует Scene), диалог сравнения
src/LabProject.Check   консольная диагностика
```

Соответствие старому проекту: `algorithms/*.py` → `Algorithms/`, `core/benchmark.py` →
`Core/Benchmark.cs`, `core/cache.py` → `Core/BenchmarkCache.cs`, `core/approximation.py` →
`Core/Approximation.cs`, `db/database.py` → `Db/`, `gui/*` → `LabProject.App` + `Visual/`.

База данных - `data/results.db` рядом с .exe, **схема идентична** Python-версии: старый
файл можно скопировать в эту папку, накопленные замеры подхватятся.

## Отличия от Python-версии (вынужденные)

* **Timsort** → `Array.Sort` (introsort); ключ `timsort` сохранён для совместимости с БД.
* Замеры идут в потоке со стеком 512 МБ: рекурсивные алгоритмы степени при n до 10⁶
  иначе убили бы процесс (в Python это был перехватываемый `RecursionError`).
* Перед экспериментом выполняется «прогрев» (3 вызова, в БД не пишутся), чтобы JIT-компиляция
  не исказила первую точку; в проекте отключена ступенчатая JIT-компиляция.
* Аппроксимация `T = C·f(n)` считается по замкнутой формуле МНК (результат тот же, что у `curve_fit`).
* Исправлена скрытая ошибка кэша: при неполном кэше (например, 2 запуска из 5) старые
  строки теперь удаляются перед пересчётом, а не дублируются.
* `check_setup`: проверки идут на временной БД, ваши данные не затрагиваются.
